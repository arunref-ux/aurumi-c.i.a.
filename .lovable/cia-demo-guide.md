# Controlled fictional demonstration guide

Use fictional/sanitized data only. The identity selector simulates roles, not secure login. Work is local to this browser; never reset a protected store. No external leads, tasks, emails, commissions or signed contracts are created.

## A — Prospective customer
Open `/business-fit/start`; choose Small distributor or enter hotel PMS/Tally/attendance. Complete the questionnaire, generate the preliminary report, print A4, then restart. No contact is needed. Optionally request consultation with contact consent; demonstrate saved request after reload and internal consultation intake. Explain self-reported guidance and uncertain connector availability.

## B — Professional
Select an eligible prototype professional. Assign/qualify an intake, confirm self-reported/unverified carry-forward and create Assessment. Supplement requirements/evidence; obtain independent assessment approval. Create Solution from the immutable hand-off, preserve uncertain integrations, and obtain independent approval. Proposal uses its pinned solution/price book; submit, independently approve and issue that exact version. Acceptance is simulated, not a signature. Engagement needs separate commencement authorization. Use `/engagements/delivery_hotel` to show tasks, exact-version acceptance, obligations, 120→80-minute partial improvement and fresh review; completion never certifies unachieved targets. A stable retry key preserves duplicate-safe mock operations.

## C — Management and partner
Overview shows scoped derived counts. Administrator manages Network qualifications/affiliations, eligibility and suspension; Manager governs assigned delivery. Select Liam to show the reseller engagement but deny unrelated hotel records and commercial source/report access. Explain that a partner proposal is proposed terms, not real commissions. Reviews, task references, health, demand and continuation remain simulated; usage is not evidence of value.

## Reproducible validation
`bunx vitest run` executes the full suite. `python3 scripts/phase7_browser_validation.py` runs disposable public/mobile reporting, task save/reload, keyboard and denial checks at localhost:8080. With `PHASE7_CAPTURE=1`, the Phase 7 journey/print tests save acknowledged fictional envelopes under `/tmp` for report inspection. Do not restore real customer data for demonstration.
